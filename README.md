# ESP32 Project Hub

Welcome to my collection of MicroPython projects! This repository is a personal archive and a sharing space for IoT enthusiasts.

## 🎯 Why This Repository Exists

I started this repository for two main reasons:

1. **To preserve my code** – I didn't want to lose my experiments over time. Everything is now safely version-controlled here.
2. **To inspire others** – If you're passionate about IoT and embedded systems, I hope these examples give you ideas or a starting point for your own creations.

All projects are developed for the **ESP32 DevKit V1**, but most of the code should work on other ESP32 boards and even other MicroPython-compatible microcontrollers with minor adjustments.

## 📁 Projects List

Below are the current projects in this repo. Click the links to view each code file.

| Project | File Link | Hardware Needed | Brief Description |
|---------|-----------|-----------------|--------------------|
| Blinky LED | [`blink.py`](./blink.py) | 1x LED, 1x resistor (220Ω) | The classic "Hello World" of microcontrollers. Makes an LED blink on and off at 0.5 second intervals. Perfect for testing your ESP32 setup. |
| Police Siren | [`police_siren.py`](./police_siren.py) | 2x LEDs (red/blue), 2x resistors (220Ω), 1x buzzer, 1x push button | Simulates police lights and siren! Press the button to toggle between siren mode (alternating LEDs + buzzer) and steady red light mode. |

## 🔁 How to Contribute (Pull Requests)

I'm very open to seeing your ideas and improvements! If you'd like to contribute:

1. **Fork** this repository.
2. **Create a new branch** for your changes.
3. **Make your improvements** – add a new project, optimize existing code, fix bugs, or improve documentation.
4. **Submit a Pull Request (PR)** with a clear description of what you changed and why.

Any kind of contribution is welcome – from fixing typos in comments to adding full new projects. If you have an idea you'd like to discuss before coding, feel free to open an **Issue** first.

Let's build and learn together! 🚀
